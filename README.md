# erp42 차량 PID 속도제어 
자율주행 차량 ERP42에 직접 PID 제어기를 구현하여 목표 속도와 실제 속도 간의 오차를 최소화하였습니다. PWM 제어 신호를 생성하여 실제 차량에 적용하였고, MATLAB을 통해 시뮬레이션도 진행하였습니다.
